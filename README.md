# 📊 Retail Sales Analytics

A complete Retail Sales Analytics Dashboard built using **Python, Streamlit, SQLite, Pandas, Plotly and OpenPyXL**.

---

## 🚀 Features

- 🔐 Login System
- 🛒 Sales Management
- 📈 Interactive Dashboard
- 📊 Reports & Analytics
- 📂 Upload Company Sales Data (CSV)
- 📥 Export Reports to Excel
- 🔍 Search & Filter Sales
- ✏️ Edit & Delete Sales
- 💾 SQLite Database

---

## 🛠 Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- OpenPyXL

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clonegit clone https://github.com/vishukaushik789/Retail-Sales-Analytics.git
```

### 2. Open Project

```bash
cd Retail-Sales-Analytics
```

### 3. Install Requirements

```bash
pip install -r requirements.txt
```

### 4. Run the Project

```bash
streamlit run app.py
```
